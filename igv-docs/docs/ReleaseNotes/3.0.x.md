# IGV 3.0 - January 2026

IGV 3.0 includes a number of new features and improvements, as well as some changes to the user interface.

## Track layout

The track layout has been redesigned to make better use of the available vertical space and to provide more flexibility in how tracks are displayed. Major changes include:

* The data window is no longer divided into panels. Instead, all tracks are now displayed in a single scrollable data window and the tracks themselves can also have scrollbars if they contain more data than accommodated by their height.
* The sequence track is now displayed at the top of the IGV window by default; the gene annotation track is still displayed by default at the bottom of the window. When other tracks are loaded they are added to the display just above the gene annotation track.
* Tracks now have grab handles on the left side of the track name panel that can be used to drag and reorder the tracks. 
* To select tracks [ADD HOW TO SELECT TRACKS]
* SEG files are loaded as a single track with multiple samples, instead of multiple tracks with one sample each.

## Menu layout

The IGV menu bar has been **reorganized** and has **additional features**. Major changes include: 

1. The menu items for controlling sessions have been moved from the *File* menu to a new top-level **Sessions** menu.

2. The **Genomes** menu has a new entry for selecting the default annotations tracks for a reference genome. 
Loading hosted genomes has also changed, as described in the section on [_Reference genomes_](.#reference-genomes) below.

3. Hosted tracks previously found in _File > Load from Server_ are now found in the new top-level **Track Hubs** menu. 
The _Track Hubs_ menu also provides access to public track hubs hosted by the UCSC Genome Browser and other track hubs that can be accessed via URL.
The section below on [_Track hubs and hosted tracks_](.#track-hubs-and-hosted-tracks) describes this in more detail.

4. Loading sample information files is now done from a new top-level **Sample Info** menu; the _File_ menu can no longer be used to load sample information files.
Other items related to sample attributes have been moved from the _Tracks_ menu to the new _Sample Info_ menu.

5. The **Tracks** menu has been removed. Some items were moved to the new _Sample Info_ menu, as described above. Other items that could be accomplished in different ways have been removed from the menus:
    * _Set Track Height_: Multi-select the tracks to be changed, right-click on one of them, and select _Set Track Height_ from the pop-up menu. To multi-select tracks, use _Control_ (or _Command_ on Mac) _+ click_ on the track names to select individual tracks, or _Shift_ _+ click_ to select a range of tracks.
    * _Fit Data to Window_: Use the ![](../UserGuide/img/icon_fit_to_window.png){height=28} button in the toolbar instead.

## Reference genomes 

When selecting a reference genome from the _Genomes > Load Genome from Host_ menu, you will now see a list of all genomes hosted at the UCSC Genome Browser GenArk site and selected other genomes. The list of GenArk hosted genomes is retrieved in real time from the UCSC server, so it is always up to date. In previous releases, the list of hosted genomes contained a much shorter hand-curated list of genomes.

![](../UserGuide/img/genomes-hosted.png){height=440}

By default, the curated genomes from earlier IGV releases is presented at the top of the list. The list can be **filtered** by typing one or more terms in the search box at the top of the window. Or **sort** the list by clicking on any of the column headers. To **select** a genome, click on the row for that genome and then click the _Load_ button.

!!! Tip " " 
    When viewing data in the IGV window, the UCSC server will be accessed on demand to load the sequence and annotations in view as you move between different loci in the genome. Alternatively, you can download the sequence and annotations to your local computer by checking the radio buttons for _Download sequence_ and _Download annotations_. This will allow IGV to function without an internet connection, but may require considerable disk space as it will download the complete sequence and annotation files.

When you click the _Load_ button, a new window will open that allows you to select the **default annotation tracks** to be loaded with the genome. The tracks are presented in categories, and you can expand or collapse a category by clicking on the + or - sign to the left of the category name. Note that some categories are presented as collapsed when you open the window. Select one or more tracks by checking the boxes by their name, and click _OK_.

![](../UserGuide/img/select_default_annotations.png){height=440}

Once loaded, the selected genome will also be added to the _genome dropdown menu_ in the IGV toolbar. Whenever you load the genome from the dropdown, the default annotation tracks you selected will be loaded automatically. To **change the default annotation tracks** for a genome, use the _Genomes > Select Default Annotations_ menu item.

## Hosted tracks and track hubs 

Hosted tracks that previously were loaded via the _File > Load from Server_ menu are now made available through the **Track Hubs** menu. The tracks are organized into categories that are listed at the top of the menu. Click on a category name to see the list of available tracks in that category. 

At the bottom of the _Track Hubs_ menu are two items for connecting to **UCSC-style track hubs**.

1. Click on _Select Track Hubs_ to open a window that lists all public track hubs from **the UCSC Track Hub Registry** that are relevant for the current reference genome. The list is retrieved in real time from the UCSC server, so it is always up to date. The list can be **filtered** by typing one or more terms in the search box at the top of the window. Or **sort** the list by clicking on any of the column headers. **Select** one or more hubs by checking the boxes by their name and then click the _OK_ button to add them to the _Track Hubs_ menu.

2. Click on _Add Track Hub from URL_ to access **any track hub by entering its URL**. This opens a window in which you can paste the URL of the hub's `hub.txt` file and clicking ok will add the hub to the *Track Hubs* menu. The URL can link to a hub on your local intranet or a public hub on the internet. 

To **load tracks from a hub** that was added to the *Track Hubs* menu by either of the above methods, click on the hub name in the menu. This opens a window that lists all tracks in the hub. A warning will be presented if the hub does not contain any tracks that are compatible with IGV. Select one or more tracks by checking the boxes by their name, and click _OK_ to load them.

To **remove hubs from the menu**, click on _Select Track Hubs_, uncheck the hubs to be removed, and click _OK_. If any hubs are added by URL, they are also added to the list in the _Select Track Hubs_ window and can be removed in the same way.

!!! Tip " " 
    The hubs remain in the _Track Hubs_ menu across IGV sessions. The state of the menu is stored in the `hubs.txt` file in the `igv` folder in your user home folder. 

## Sessions

The session **file format** has been updated. Starting with IGV 3.0, session files are saved in JSON format that is compatible with sessions created in IGV-Web. The new format is not compatible with previous releases of the IGV desktop application, so sessions created in IGV 3.0 cannot be loaded in earlier versions. However, sessions created in earlier versions of IGV can be loaded in IGV 3.0. The new session file format is further described [HERE ADD LINK TO SESSION FILE FORMAT DOC].

## Visual themes

A new feature in the _General_ tab of the _View > Preferences_ window allows you to select a **visual theme** for IGV. Two of the themes support a **dark mode**, which may be easier on the eyes in low-light environments. Switching to a different theme will require a restart of IGV before it takes effect.

## Miscellaneous new features

* A new track type for displaying **Hi-C contact maps**. 

* New features for **alignment tracks**:

    * Automatically re-sort the alignments when the view is changed to a different locus. This is enabled via a preference. [IS THIS FOR ALL SORT MODES OR JUST FOR SORT BY BASE?]
  
    * Color alignments by the supplementary flag in the BAM file.
  
    * Group alignments  such that all selected alignments are grouped together. To select an alignment (and its mate if the track has paired-end data) Ctrl-click on the alignment (Cmd-click on MacOS). 

* If a MANE transcript track has been loaded, you can now enter **HGVS (Human Genome Variation Society) notation** in the search box to navigate to the corresponding variant locus. For example, entering `NM_000546.5:c.215C>G` will navigate to the locus of the TP53 gene where a C to G mutation occurs at position 215 of the coding sequence. Supported notations: genomic (g.), coding (c.), and protein (p.). [IS IT CORRECT THAT A MANE TRACK IS REQUIRED?]
