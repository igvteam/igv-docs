## IGV menu layout

The IGV menu bar has been **reorganized** and has **additional features**. Major changes include: 

1. The menu items for controlling sessions have been moved from the *File* menu to a new top-level **Sessions** menu.

2. The **Genomes** menu has a new entry for selecting the default annotations tracks for a reference genome. 
Loading hosting genomes has also changed, as described in the section on [_Reference genomes_](.#reference-genomes) below.

3. Hosted tracks previously found in _File > Load from Server_ are now found in the new top-level **Track Hubs** menu. 
The menu also provides access to public track hubs hosted by the UCSC Genome Browser and other track hubs that can be accessed via URL.
The section below on [_Track hubs and hosted tracks_](.#track-hubs-and-hosted-tracks) describes this in more detail.

4. Loading sample information files is now done from a new top-level **Sample Info** menu; the _File_ menu can no longer be used to load sample information files.
Other items related to sample attributes have been moved from the _Tracks_ menu to the new _Sample Info_ menu.

The **new menu structure** is as follows:

* **File**
    * Load Tracks from File
    * Load Tracks from URL
    * Save PNG Image
    * Save SVG Image
    * Exit
* **Genomes**
    * Load Genome from Host
    * Load Genome from File
    * Load Genome from URL
    * Select Default Annotations
    * Remove Genomes
* **Track Hubs**
    * Select Track Hubs
    * Load Track Hub from URL
    * [ _List of categories of hosted tracks for the current reference genome_ ]
    * [ _List of selected track hubs_ ]
    * [ _List of track hubs already loaded by URL_ ]
* **Sample Info**
    * Load Sample Info from File
    * Load Sample Info from URL
    * Sort Tracks by Attribute
    * Group Tracks by Attribute
    * Filter Tracks by Attribute
    * Export Track Names and Attributes
* **Sessions**
    * New Session
    * Load Session from File
    * Load Session from URL
    * Save Session
    * Reload Session
    * Autosaved Sessions 
* **View** _(has not changed in 3.0)_
    * Preferences
    * Show Name Panel
    * Show Name Panel Width
    * Show Attribute Display
    * Select Attributes to Show
    * Show Header Panel
    * Reorder Panels
    * Add new Panel
    * Go to 
* **Regions** _(has not changed in 3.0)_
    * Region Navigator
    * Gene Lists
    * Export Regions
    * Import Regions
* **Tools** _(has not changed in 3.0)_
    * Run Batch Script
    * Run igvtools
    * Find Motif
    * BLAT
    * Combine Data Tracks
* **Help** _(has not changed in 3.0)_
    * User Guide
    * Help Forum
    * About IGV
